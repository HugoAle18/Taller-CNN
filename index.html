Fase 6 · Deployment

Despliegue SaaS

Modelo unificado sistema_inteligente_unificado.keras con inferencia adaptativa y redimensión Lanczos para producción en vivo.

🚀
PASE AUTORIZADO A PRODUCCIÓN
Ambos modelos superan los umbrales institucionales · Sistema listo para inferencia en vivo
📦 Artefacto Unificado
La API funcional de TensorFlow fusiona ambos modelos en un único archivo .keras multi-salida, facilitando portabilidad a cualquier servidor.
🔄 Inversión Adaptativa
Analiza píxeles periféricos. Si detecta fondo claro (imágenes externas), invierte la matriz (1.0 − imagen) antes de inferir, garantizando predicciones correctas.
🔍 Redimensión Lanczos
Cualquier imagen externa se redimensiona a 28×28 px con el algoritmo Lanczos de alta calidad, preservando la máxima nitidez de bordes para la red.

inferencia.py 
# Cargar modelo unificado
modelo = tf.keras.models.load_model(
  'sistema_inteligente_unificado.keras'
)

# Preprocesamiento adaptativo
img = Image.open(ruta).resize((28,28), Image.LANCZOS)
arr = np.array(img).astype('float32') / 255.0

# Inversión si fondo claro
if arr[:3,:3].mean() > 0.5:
    arr = 1.0 - arr

pred = modelo.predict(arr.reshape(1,28,28,1))
confianza = np.max(pred) * 100
clase = clases[np.argmax(pred)]
